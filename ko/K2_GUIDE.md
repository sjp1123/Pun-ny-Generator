# K2 한국어 말장난 모으기 — 작성 요령

목표: 한국어 말장난 **100개**. 이 자료로 (1) 사람이 얼마나 비슷한 소리로 말장난을 만드는지(소리 거리 기준), (2) 청자 모델이 숨은 말을
되찾는지, (3) 관문 문턱, (4) 판정기 검증을 한다(`ko/DESIGN.md` 4절).

## 파일

- 양식: [`ko/k2/k2_template.csv`](k2/k2_template.csv) — 예시 3줄이 들어 있다. 복사해서 **`ko/k2/local/k2_puns.csv`**로 저장하고
  거기에 채운다. `ko/k2/local/`은 깃에 올라가지 않는다(웹에서 가져온 것이 섞일 수 있어서).
- 엑셀에서 열고 같은 이름(CSV UTF-8)으로 저장한다.

## 열

| 열 | 쓰는 것 | 예 |
|---|---|---|
| 번호 | 1, 2, 3 … | 1 |
| 형식 | `퀴즈`(묻고 답하는 넌센스 퀴즈) / `한줄`(한 문장) / `기타` | 퀴즈 |
| 말장난 | 문장 전체. 퀴즈는 `Q: … / A: …` | Q: 친구와 함께하면 올라가는 것은? / A: 가치 |
| 종류 | `A`(철자 다름, 소리 같거나 비슷) / `B`(같은 철자, 다른 뜻) / `C`(어절 경계·합성, 예: 열바다) / `D`(외래어 섞기) / `E`(그 밖) | A |
| w_p | 문장에 **실제로 쓰인** 말(퀴즈는 대개 답) | 가치 |
| w_a | 함께 떠올라야 하는 **숨은** 말. B 갈래는 w_p와 같은 말 | 같이 |
| 뜻_p | w_p의 뜻(짧게) | 값어치 |
| 뜻_a | w_a의 뜻(짧게). B 갈래는 숨은 쪽 뜻 | 함께 |
| 출처 | `직접`(내가 지음) / `기억`(어디서 들음, 출처 모름) / 웹 주소 | 직접 |
| 웃김 | 1~5 (내 느낌, 지금 바로) | 3 |
| 비고 | 아무 메모 | |

## 고르는 기준

- **A·B 종류가 60개 이상**이면 좋다(1단계에서 실제로 쓰는 것). C·D·E도 모아 두면 한국어 말장난이 어떻게 생겼는지 보는 데 쓴다.
- 너무 유명해서 모델이 외웠을 것 같은 것도 괜찮다(출처 열에 `기억`). 그 표시로 나중에 나눠 본다.
- 성적·비하 표현은 빼도 된다(넣으면 비고에 적어 둔다).
- 웃기지 않은 것도 넣어도 된다. 웃김 열이 그것을 가린다.
- 한 개를 오래 붙잡지 말고 빠르게. 대략 2~3시간이면 된다.
