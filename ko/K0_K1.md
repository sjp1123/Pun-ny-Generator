## K0 도구

| 도구 | 결과 |
|---|---|
| Kiwi (kiwipiepy 0.24.1) | 설치됨. Windows에서 바로 동작 |
| g2pkk 0.1.2 (표준 발음 규칙) | Windows에서 MeCab(eunjeon) 빌드가 실패한다(Visual Studio 필요). g2pkk가 MeCab에서 쓰는 것은 품사 태깅뿐이라 **Kiwi로 바꿔 끼웠다**(`ko/src/ko_g2p.py`). 축약(했 = 하+었)은 'VV+EP'로 묶어 MeCab-ko 꼴로 준다 |
| 표준 발음 확인 | Claude가 고른 예 **20/20**(같이→가치, 국물→궁물, 꽃잎→꼰닙, 독립→동닙, 학교→학꾜 …), 문장 속 연음도 맞음(낮에는 → 나제는). 연구자가 고른 예로도 확인할 것 |
| Polyglot-Ko 1.3B | CPU에서 동작. 맞는 문장을 높게 본다: 같이/가치 −23.4 vs −30.5, 우산/우선 −23.2 vs −37.3 |
| 뜻 탐침(B 갈래) | 방향은 맞다: "빨간 사과를 샀다"에서 과일 −59.7 vs 사죄 −71.2. 하지만 "먼저 사과를 했다"에서 사죄 −72.3 vs 과일 −72.7로 차이가 작다. 탐침 문구 자체의 사전 확률을 빼는 보정이 필요하다(K3) |
| 표준국어대사전 API | 연구자 인증키(환경 변수 `STDICT_KEY`, 키는 출력·저장하지 않음)로 동작. `ko/src/stdict.py`, 결과는 `ko/k1/local/`에 캐시(올리지 않음) |

## K1 A 갈래 쌍 (`ko/scripts/k1_pairs.py` → `ko/k1/`)

- 명사: wordfreq 한국어 상위 3만(형태소 단위) → Kiwi 일반명사 한 형태소, 2음절 이상 → **13,907개**. 철자와 발음이 다른 명사 2,535개.
- **d0 (철자 다름, 발음 같음): 43쌍.** 좋은 예: 걸음/거름, 산림/살림, 시련/실연, 실업/시럽, 바람/발암, 저녁/전역, 폭우/포구, 수능/순응,
  학문/항문, 열애/여래. 걸러야 할 것: 외래어 표기 변이(비전/비젼, 케익/케잌, 캡처/캡쳐, 오랜만/오랫만), wordfreq의 형태소 조각
  (모리, 마지, 무너, 이너, 잡이). 거르면 25~30쌍 안팎으로 보여 **기준(30쌍)의 경계**다. 사전 확인(API)이 있으면 정확히 센다.
- **d1 (자모 하나 차이): 23,156쌍**(치환 21,356, 더하기·빼기 1,800). 예: 내사/대사, 네모/메모, 생산/생선, 고기/공기, 과자/과장.
  아직 소리 비슷함 문턱이 없다(영어처럼 K2 사람 말장난으로 정한다). 쌍은 충분하다.
- 한 음절 명사(공/곰)는 조사 조각과 섞여 이번 목록에서 뺐다.

## 사전 확인 (`ko/scripts/k1_dict.py`, 요약 `ko/k1/k1_dict_summary.json`)

- **A 갈래 d0: 43쌍 → 33쌍**이 두 낱말 모두 사전 명사(참고 항목 '→ …'만 있는 것 제외)이고 표기 변이가 아니다. 빠진 것: 비전/비젼,
  케익/케잌, 캡처/캡쳐, 오랜만/오랫만, 무늬/무니 등. 남은 33쌍에도 드문 낱말(모리, 이너)이 섞여 있어 연구자가 고른다
  (`ko/k1/local/curate_d0.csv`, 쓸만함 Y/N). 기준 30쌍은 연구자 고르기 뒤에 다시 본다.
- **B 갈래**: 빈도 상위 명사 3,000개 중 어깨번호가 다른 명사 뜻이 2개 이상인 낱말이 1,780개다. 표준국어대사전은 드문 동형어를 많이
  싣고(사과에 표제어 8개, 그중 조선 시대 군직) 어느 뜻이 흔한지 알려 주지 않는다. 빈도순 목록은 둘째 뜻이 드문 한자어로 가득하고,
  한 음절 고전 동형어(눈, 말, 밤)는 조사 거르기에 걸려 빠졌다 → **이 방법은 쓰지 않는다.**
- 대신 **국립국어원 「한국어 학습용 어휘 목록」(2003, 5,965낱말, 동형어 번호와 등급 포함, 공공누리 제1유형)**에서 같은 낱말이 다른 번호로
  두 번 이상 나오는 명사(눈01 눈 / 눈02 눈[雪])를 B 갈래 후보로 쓴다. 흔한 뜻만 들어 있는 목록이라 연구자가 고를 양이 크게 준다.

## 연구자 고르기 뒤 (2026-11-20)

- **A 갈래 d0**: 연구자가 8쌍을 뺐다(수탁, 여래, 이너, 장내, 직영, 모리, 국영, 남우가 든 쌍) → **25쌍**(`ko/k1/d0_curated.csv`).
  **기준 30쌍에 못 미친다** → 4절대로 A 갈래는 sub·indel(자모 하나 차이) 위주로 가고 d0는 25쌍을 모두 쓴다.
- **B 갈래**: 「한국어 학습용 어휘 목록」(국립국어원 2003, 공공누리 제1유형)에서 같은 명사가 다른 동형어 번호로 2번 이상 나오는 낱말
  **122개(260뜻)** — 기준 50쌍을 넘는다(`ko/scripts/k1_homographs.py` → `ko/k1/homograph_candidates.csv`). 눈(신체 / 내리는 눈),
  다리(신체 / 교량), 말(~과 글 / 동물), 밤(어두운 때 / 열매), 배(신체 / 배 / 열매), 사과(沙果 / 謝過), 바람(~이 불다 / 소원), 김, 감, 고개 등.
  목록의 동형어 번호는 2003년 판 사전 번호라 지금 표준국어대사전의 어깨번호와 어긋난다(말05 → 지금 사전에서는 십이지의 '오').
  그래서 뜻은 목록의 풀이 열(원어 한자, '동물' 같은 단서)로 보이고, 사전 뜻풀이는 원어 한자로 다시 맞춘다(K3 전).
- 연구자 고르기 남음: `ko/k1/local/curate_b.csv`에 말장난에 쓸 두 뜻의 번호(예: `1,4`). 뜻이 비슷한 한자어(과정 過程/課程)는 비운다.
