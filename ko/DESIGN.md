# 한국어 말장난 생성 (K 계열) 설계

작성 2026-11-17, 결정 반영 2026-11-20. 영어 E5(세 단계 생성 + 청자 모델로 고르기)를 한국어로 옮긴다. 이 문서는 설계이고, K4 파일럿 전에
사전 등록(`ko/PREREG_K.md`)으로 옮긴다. 코드와 자료는 모두 `ko/` 아래에 둔다(영어 코드 `src/`, `experiments/`는 가져다 쓴다).

## 0. 정한 것 (2026-11-20)

1. **범위는 1단계만**: 한 단어(명사)의 말장난. 어절 경계를 넘는 말장난("열바다"/열받아), 외래어 섞기("킹콩")는 다루지 않는다.
2. **1단계 안에 두 갈래**를 둔다.
   - **A 갈래 — 소리 쌍**: 철자가 다르고 소리가 같거나 비슷한 두 낱말(같이 [가치] / 가치, 사자 / 사장). 영어 E5와 같은 틀.
   - **B 갈래 — 같은 철자 동음이의어**: 철자도 소리도 같고 뜻이 다른 낱말(사과: 과일 / 사죄, 배: 과일 / 선박 / 신체).
     연구자가 원했다(“가능하다면”). 영어 틀을 뜻 단위로 바꿔야 하므로 K0~K1에서 가능한지부터 본다(3절).
3. **K2 사람 말장난 100개는 연구자가 모은다**(4절의 양식).
4. **저장소**: 이 저장소의 `ko/`.

## 1. 영어 E5에서 배운 것 (처음부터 넣는다)

| 영어에서 겪은 일 | 한국어에서는 |
|---|---|
| 쌍의 소리가 사람 말장난보다 멀었다(steep/sleep) | K2의 사람 말장난으로 **소리 거리의 기준부터** 잰다 |
| 여러 발음 중 가까운 것을 써서 가짜 동음 쌍이 생겼다(nice/niece) | 표준 발음 하나만 쓴다(g2pK) |
| w_p가 w_a 자리 품사를 못 가졌다("My nice") | 명사만, S1에 품사 검사 |
| LLM 판정기 세 질문이 모두 실패했다 | 판정기를 주 측정으로 쓰지 않는다. 쓴다면 연구자 라벨로 먼저 검증 |
| 파일럿 7번, 매번 결과를 보고 고쳤다 | **파일럿은 최대 3번**. 기준과 실패했을 때 할 일을 시작 전에 적는다 |
| S4는 연구자 블라인드 A/B로 정했다 | 설계 선택은 연구자 블라인드 A/B로(모국어라 더 정확하다) |
| 단계를 나눠 규칙은 지켰지만 재미가 약했다 | 넌센스 퀴즈 형식이 이 약점을 줄이는지 본다 |

## 2. A 갈래 — 소리 쌍 (영어 틀 그대로)

| 부분 | 영어 E5 | 한국어 |
|---|---|---|
| 생성 | S1(w_a만 앎) → S2(코드) → S3(w_p만 앎), S4 없음 | 같음. 프롬프트만 한국어 |
| S2 | 대소문자, a/an | **조사 이형태**: 받침 유무로 은/는, 이/가, 을/를, 와/과, ㄹ받침 예외 포함 으로/로 |
| 형식 | 수수께끼, 한 줄 | **넌센스 퀴즈**(Q/A), 한 줄 |
| 발음 | CMUdict 첫 발음 → ARPAbet | g2pK(Windows는 g2pkk) 표준 발음 → 자모 → IPA |
| 소리 거리 | panphon 자질 거리, 사람 말장난 중앙값 이하 | 같은 panphon + 자모 편집 거리. 문턱은 K2 사람 말장난으로 |
| 쌍 층 | d0, sub, indel | d0(철자 다름·발음 같음), sub(자모 하나 치환), indel(자모 하나 더하기·빼기) |
| 어휘 | CMU ∩ 빈도 상위 2만, WordNet 품사 | wordfreq 한국어 빈도 상위 ∩ Kiwi 명사(NNG) |
| 뜻풀이 | WordNet 흔한 뜻 | 표준국어대사전·우리말샘(오픈 API, 무료 인증키 필요) |
| 뜻 거리 | word2vec cos < 0.3 | 한국어 임베딩(fastText ko 또는 다국어 문장 임베딩). 문턱은 분포를 보고 |
| 청자 | Pythia-1.4B, 발음 상위 100 + w_a, 표제어 합 | **Polyglot-Ko 1.3B**(Pythia와 같은 GPT-NeoX). 조사까지 붙인 어절로 채점, Kiwi로 표제어 합 |

## 3. B 갈래 — 같은 철자 동음이의어 (뜻 단위로 바꾼 틀)

영어 틀은 **낱말 두 개**(w_p, w_a)를 다룬다. B 갈래는 **한 낱말의 뜻 두 개**(뜻 p, 뜻 a)를 다룬다.

- **쌍**: 사전에서 같은 표기로 나뉜 명사 동형어(표준국어대사전의 사과¹ / 사과² 같은 어깨번호)에서 두 뜻 모두 흔한 것.
  뜻 거리가 먼 것만(같은 뜻의 갈래가 아니라 다른 낱말이어야 한다).
- **생성**: 단계 분리를 뜻으로 옮긴다.
  - S1: **뜻 a만 안다** — "'사과'(사죄)라는 뜻으로 끝나는 평범한 문장".
  - S2: 바꿀 글자가 없으므로 그대로(낱말은 이미 같다).
  - S3: **뜻 p만 안다** — 앞부분에 뜻 p(과일) 쪽 말을 1~4개.
  - 검사: 낱말이 끝에 한 번, 뜻 a 쪽 낱말이 새지 않음 대신 "뜻 a를 직접 풀어 쓰지 않음", 형식, 길이.
- **청자**: 발음 후보가 같은 문자열이라 영어의 A를 쓸 수 없다. 대신 **뜻 탐침**: 문장 뒤에 "여기서 '사과'는 과일이다" / "… 사죄다"를
  붙였을 때 Polyglot-Ko의 로그 확률로 두 뜻의 사후 확률을 낸다. **A_B = 두 뜻 사후 분포의 엔트로피**(두 뜻이 함께 서면 높다).
  관문과 점수는 K2의 B 갈래 사람 말장난과 대조 문장(한 뜻만 서게 바꾼 문장)으로 맞춘다.
- **가능성 확인(K0~K1)**: (1) 동형어 목록과 뜻풀이를 얻을 수 있는가(사전 API), (2) 흔한 명사 동형어 쌍이 50개 이상인가,
  (3) 뜻 탐침이 K2의 B 갈래 말장난과 대조 문장을 우연보다 잘 가르는가. 셋 중 하나라도 안 되면 B 갈래는 접는다.
- 위험: 뜻 탐침은 영어에서 검증한 적이 없는 새 지표다. 사전의 뜻 나눔이 사람이 느끼는 뜻 차이와 다를 수 있다.

## 4. 단계와 진행 기준

| 단계 | 누가 | 하는 일 | 진행 기준 |
|---|---|---|---|
| K0 도구 | Claude (이 PC) | Kiwi, g2pkk, jamo, Polyglot-Ko 1.3B, 사전 API 확인 | g2pK가 연구자가 고른 발음 예 20개를 맞힘 |
| K1 쌍 | Claude (이 PC) | A 갈래 쌍(층별 개수), B 갈래 동형어 쌍 | A: d0 ≥ 30쌍(모자라면 sub·indel 위주). B: 흔한 동형어 ≥ 50쌍 |
| K2 사람 말장난 | **연구자** | 한국어 말장난 100개 모으기와 표시(`ko/K2_GUIDE.md`) → 대조 문장(코드) → 블라인드 라벨 | 1단계(A·B) 말장난이 60개 이상 |
| K3 청자 검증 | GPU 조금 | A: w_a 되찾기, B: 뜻 탐침. 관문 문턱 | 우연보다 뚜렷이 높음. 아니면 그 갈래를 멈춤 |
| K4 파일럿 | GPU, **최대 3번** | 생성기 후보 EXAONE 4.0 32B(연구용), Qwen 계열 32B(4비트). 연구자 블라인드 평가 | 사전 등록에 적은 기준 |
| K5 사전 등록·본 실행 | 함께 | `ko/PREREG_K.md`, 태그 `prereg-k`, 본 실행, 연구자 평가 | — |

## 5. 위험

| 위험 | 대응 |
|---|---|
| A 갈래의 철자 다른 같은 소리 쌍이 적다 | K1에서 먼저 센다. 적으면 sub·indel 위주로, 사실을 적는다 |
| 한국어 말장난 자료가 없다 | K2를 연구자가 모은다. 웹에서 모은 것은 로컬에만 둔다(`ko/k2/local/`, 깃에 올리지 않음) |
| 조사·어미 | 명사만. 조사 이형태 규칙 |
| 문장 속 발음 변화(연음 등) | 청자 후보를 문장 속 발음으로도 확인(K0) |
| Windows에서 MeCab | g2pkk, Kiwi를 쓰거나 GPU 머신(Linux)에서 전처리 |
| B 갈래 뜻 탐침이 작동하지 않음 | K3에서 확인하고 안 되면 접는다 |
| 사전 API 인증키 | 연구자가 무료로 받아 환경 변수로만 둔다(코드·채팅에 넣지 않음) |
